📐 Formulario Oficial — II Trimestre (3ro BGU)

1. Función Exponencial: f(x) = aˣ⁺ʰ + k

• Dominio: Todos los reales ℝ.

• Asíntota Horizontal: y = k.

• Recorrido (si a > 1): (k, +∞).

• Corte Eje Y: Evaluar x = 0 ⇒ (0, aʰ + k).

2. Propiedades de los Logaritmos

• Producto: log_b(M · N) = log_b(M) + log_b(N)

• Cociente: log_b(M / N) = log_b(M) - log_b(N)

• Potencia: log_b(Mⁿ) = n · log_b(M)

• Fundamental: log_b(bˣ) = x

3. Función Logarítmica: g(x) = log_b(x)

• Es la inversa de f(x) = bˣ.

• Simetría: Respecto a la recta identidad y = x.

• Dominio: (0, +∞) | Recorrido: ℝ.

• Asíntota Vertical: x = 0 | Corte X: (1, 0).

4. Ecuaciones Exp. y Sucesiones

• Igualación de bases: bᵘ = bᵛ ⇔ u = v

• Sucesión Geométrica: aₙ = a₁ · rⁿ⁻¹

• Si disminuye el 50% por etapa, la razón es r = 0.5 = 1/2.
